# Tetris / Tetris OS
Two implementations of Tetris, as well as an OS that runs tetris.

`tetris.c`: Game of Tetris, using libxgfx, in C.

`tetris.zig`: The same game of Tetris, using libxgfx, in Zig.

`tetris-os.c` + associated files: a complete operating system kernel that runs the same game of tetris. Drivers are taken from [my-os](https://github.com/thecoder08/my-os).
